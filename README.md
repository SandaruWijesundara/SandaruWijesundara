## 🚀 Featured Project

### 🏙️ ColomboWaste – Municipal Administration System

ColomboWaste is a web-based municipal administration project focused on improving the digital management of municipal services.

**Key Features:**

- 🔍 Global search and citizen complaint management
- 📊 Dynamic filtering by ward, status, and date
- 📢 Civic announcements and administrative dashboards
- 🎨 Interactive and user-friendly interface components
- 📁 CSV export functionality for administrative data

**Technologies Used:**

`HTML` `CSS` `JavaScript` `PHP` `MySQL` `XAMPP`

This project has helped me gain practical experience in web development, frontend implementation, backend integration, and building functional administrative interfaces.
